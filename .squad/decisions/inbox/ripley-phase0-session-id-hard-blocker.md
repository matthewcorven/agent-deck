### 2026-02-24: Session ID Detection — Hard Blocker for Phase 0

**Author:** Ripley (Lead) · **Status:** Enforced

Session ID extraction is the #1 open risk for the Copilot CLI integration. If Phase 0 cannot determine a reliable method to detect/extract session IDs from the Copilot CLI, Phase 3 (Session Detection + Resume) is blocked.

**Gate:** Phase 0 exit criteria now require an explicit finding on session ID extraction viability and a documented fallback strategy.

**Fallback strategies (in priority order):**
1. Filesystem discovery from `~/.copilot/` storage files
2. Synthetic IDs generated by agent-deck with `--continue`-only resume
3. Defer Phase 3 entirely until ACP provides structured session IDs in Phase 7+

Phase 1 may proceed regardless — config surface has no session ID dependency. Phase 3 is hard-blocked.
